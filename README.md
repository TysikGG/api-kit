# api-kit

Монорепа клиентов к сервисам автоматизации. Каталог в корне — один сервис. Внутри него `js/` и `python/` живут отдельно: своя версия, свой README, своя публикация в npm или PyPI.

Документация собирается как GitBook и автоматически выкладывается на GitHub Pages при пуше в `main`.

## Сервисы

### GrizzlySMS

Пользовательский протокол sms-activate (номер, SMS, цены, справочники) и партнёрские пуши SMS и звонков.

- [JavaScript](grizzly-sms/js)
- [Python](grizzly-sms/python)
