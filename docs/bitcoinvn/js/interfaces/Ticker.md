# Interface: Ticker

Public ticker from `GET /api/ticker/{base}/{quote}`.

## Properties

### rate

> **rate**: `number`

Rate including exchange fees. One base asset equals this many quote assets.

***

### volume24h

> **volume24h**: `number`

24-hour volume denominated in the quote asset.
